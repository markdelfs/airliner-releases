# Airliner

**Tune into the world.** Discover and listen to live radio on your Mac.

[Download Airliner](https://github.com/markdelfs/airliner-releases/releases/latest/download/Airliner-1.0.0.dmg)

Requires macOS 14 or later. Universal for Apple silicon and Intel. Open the DMG and drag Airliner to Applications.

Airliner is Developer ID signed and notarized by Apple. Each release includes an update appcast and SHA-256 checksums. Source code is maintained separately in a private repository.

Features include worldwide station discovery, favorites, recent listening, manual stream URLs, live metadata, system media controls, sleep timers, and searchable help. Station availability and codec support vary.
